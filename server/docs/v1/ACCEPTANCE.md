# V1 验收用例

## 核心闭环

1. **F01 无商品文生图**
   - 不创建商品，直接输入提示词，选 `qwen-image-max`。
   - 报价 → 创建任务 → 运行 → 本地作品出现图片。
   - 服务端任务、积分流水、客户端作品三方一致。

2. **F02 带商品参考图**
   - 上传商品图，选场景模板。
   - 走 DashScope `description_edit`；结果保留商品主体（人工比对）。
   - 原图不被覆盖。

3. **F03 整图改图**
   - 上传参考图，输入“把背景换成浅灰摄影棚”。
   - 结果生成新版本；原版本仍可查看。

4. **F03 局部改图**
   - 画矩形/画笔 mask，白=修改区、黑=保留区。
   - 只改 mask 区域；未选区保持稳定。
   - 不支持 mask 的模型不得显示局部入口。

## 报价与积分

5. **报价过期**
   - 报价后等待超过 5 分钟再提交。
   - 返回 `409 QUOTE_EXPIRED`；客户端保留输入并刷新报价，不扣费。

6. **余额不足**
   - 可用 Credits 小于报价。
   - 返回 `402 INSUFFICIENT_CREDITS`；不创建任务、不扣费。

7. **失败释放**
   - 供应商失败/超时。
   - 任务 `failed`；预占 Credits 释放；流水可对账。

8. **并发限流**
   - DashScope 同时提交超过 2 个。
   - 第 3 个排队或返回 `429 PROVIDER_BUSY`；不重复扣费。

## 恢复与幂等

9. **重复提交**
   - 同一 `Idempotency-Key` 重复提交。
   - 返回同一任务，不重复扣费。

10. **重启恢复**
    - 任务运行中关闭客户端。
    - 重开后任务继续/恢复；本地作品在成功后可下载。

## 本地作品与导出

11. **导出/导入**
    - 导出 `.weavia`，在另一台机器导入。
    - 作品、版本、提示词、会话文本恢复；冲突不覆盖。
    - 损坏文件被列出，不整体失败。

12. **本地为事实源**
    - 删除云存副本，本地作品仍可用。
    - 删除本地作品时提示云端仍有副本。

## 云存与存储包

13. **10GB/30 天配额**
    - 上传超过配额被拒绝，提示扩容/删除。
    - 配额内上传成功，云端可恢复。

14. **到期策略**
    - 到期后只读 30 天，之后删除云副本；本地不受影响。
    - 套餐/存储包不退款。

## 邀请与免费额度

15. **免费额度只一次**
    - 新账号邀请注册 + 邮箱验证后发 30 Credits。
    - 同一账号不能重复领取；流水有 `free_plan` 记录。

16. **邀请码**
    - 无效/过期/用尽邀请码不能注册。
    - 并发兑换不超发；`used_count` 正确。

## 安全与权限

17. **跨用户隔离**
    - 用户 A 不能读取 B 的会话、任务、云存、素材。
    - 管理端操作写审计日志。

18. **内容审核**
    - 供应商返回 `DataInspectionFailed`。
    - 任务失败、Credits 释放、错误提示可理解。

## Definition of Done

- 每个能力至少 30 个真实商品样本，人工评分 ≥4/5。
- 图片 p95 生成时间 < 60s（不含排队）。
- 任务成功率（排除供应商故障）>95%。
- 所有失败路径都有可对账的积分流水。
- 断网、重启、重复提交、报价过期均通过。
