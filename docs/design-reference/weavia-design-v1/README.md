# WEAVIA · 第一轮高保真设计

从 index.html 开始。顶部可切换 Desktop、Website 与 Design system。桌面右上角可切换 11 个评审状态。

## 浏览入口

- index.html：AI 模特创作台；侧栏切换首页、商拍、项目、任务。
- website.html：完整官网首页，支持手机宽度。
- system.html：品牌视觉与组件库；末尾含 3 条交互路径入口。
- design-spec.md：详细设计约束、页面、状态、组件和 Figma 搭建规范。
- tokens.json：色彩、字号、间距和布局变量。
- assets/：摄影概念图集与 SVG 标识方向稿。
- screens/：页面与状态截图，可直接放入 Figma 作为参考。

## 使用

双击 HTML 可预览大部分功能。图片下载建议在本机网页预览环境运行。当前会话预览地址：http://127.0.0.1:8765/outputs/weavia-design-v1/

点击“开始生成”后会经历提交与生成阶段，再出现概念结果。上传读取本地图片，但不会调用真实 AI。金额、会员权益、支付、任务恢复均不是真实服务。

AI 模特与商拍的 4 张结果使用有限概念素材复用，并非 4 张真实新生成作品。全尺寸源图为 1536×1024 的 4×2 图集，单张概念图 384×512，适于首轮视觉评审；正式案例需更换高清真实输出。

本交付是 HTML 交互原型与结构化规范，不包含原生 .fig 文件。深色仅交付基础变量及组件样例。
