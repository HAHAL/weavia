# WEAVIA 商品图片与视频试运行说明

## 本次交付的工作流

1. 在「商品库」录入名称、SKU、已核实事实、禁止声明和商品依据图；点「发起创作」直接进入创作台。
2. 在创作台选择商品、目标（商品主图／场景图／宣传图）、渠道、市场、输出语言和人群，编辑描述，再选择模型、比例、清晰度与张数。
3. 图片任务将商品资料快照和依据图送到服务端。服务端校验资料、素材归属及模型能力，保存任务并由 Worker 执行。商品图片任务必须有依据图。
4. 生成结果按实际返回数量分别保存为本机作品；作品中心可查看版本、标记「待核对／核对通过／需要修改」并下载。发布前由运营人员检查外观、包装、文字、商品事实和目标市场要求。
5. Video Studio 负责策划、编辑分镜，然后把脚本带入创作台。配置可用视频渠道后，创作台可提交文字生成视频任务。视频结果经受登录保护的文件接口下载并存于客户端素材目录。

本机 DAG 仍在客户端执行。服务端只承接有界的模型任务、路由、Credits、结果存储及历史任务。客户端内嵌 Codex 使用独立应用环境，不修改设备上已安装的 Codex 配置。

## 你需要配置

### 服务端

- 按 [`server/docs/PRODUCTION.md`](../../server/docs/PRODUCTION.md) 准备生产环境：PostgreSQL、SMTP、签名密钥、HTTPS、API 与 Worker 共用的 `ASSET_STORAGE_DIR`。真实密钥放在部署环境，不写入 Git。
- 在后台「AI Studio → 渠道」配置图片渠道、渠道级 Key、支持的模型和 Credits 价格；执行「AI Studio → 模型 → 同步到客户端」。启用真实 AI 后，检查 `GET /api/ai/models` 中图片模型的 `available=true`、能力和价格。
- 视频目前使用 DashScope 的文字生成视频适配器。先配置 DashScope 渠道与 Key，同步模型，核对 `wan2.7-t2v` 的 `text_to_video` 能力、价格、区域端点和渠道绑定。只有存在可用 DashScope 渠道时，客户端才显示视频提交入口。视频模型名和允许的时长必须与你的服务商账户实际支持的配置一致。
- 按 [`server/docs/PHASE2_ACCEPTANCE.md`](../../server/docs/PHASE2_ACCEPTANCE.md) 的只读预检检查 Provider、额度和存储。确认试运行预算后在部署环境启用 `ENABLE_REAL_AI=true`；若使用视频任务恢复功能，Worker 设置 `VIDEO_RECONCILE_ENABLED=true`。先用单任务、短时长做有费用的试运行，再扩大使用范围。

### 客户端

构建时设置 `VITE_API_MODE=live` 和生产 HTTPS `VITE_API_BASE_URL`。此地址写入客户端包，修改地址需重新构建。服务商 Key 和内嵌 Codex 的后端 Key 分别按服务端配置与客户端应用设置配置，不放在 `VITE_*` 变量。

```bash
cd client
pnpm install --frozen-lockfile
VITE_API_MODE=live VITE_API_BASE_URL=https://你的-api-域名 pnpm tauri build
```

桌面安装包仍须按目标操作系统完成签名、公证与登录回调检查，参见生产部署说明。

## 明早验收顺序

1. 登录客户端，检查模型列表和 Credits；视频未配置时应显示「暂未开放」，不能创建假视频作品。
2. 新建一件商品，填写明确的已核实事实、禁止声明和依据图；从商品卡片进入创作台。
3. 选「商品主图」，指定渠道、市场、语言，提交 1 张图片；确认任务中心状态、商品快照、作品预览、核对状态和下载。
4. 选「场景图」或「宣传图」，对同一商品生成多张；确认每张成为独立作品，而不是只保存第一张。
5. 在 Video Studio 生成或手写分镜，带入创作台。仅在 DashScope 视频模型已确认、Credits 足够并启用真实 AI 后提交一条短视频；确认 MP4 可播放、下载，并在重启客户端后能找到历史任务。

## 当前边界

- 商品库、作品核对状态和本机素材仍保存在当前客户端；服务端任务保存创作资料快照，暂不提供跨设备的商品编辑与作品审核同步。
- 视频适配器当前是文字生成视频；商品依据图不会作为视频模型输入，多镜头分镜也不会自动剪辑成片。运营人员必须核对成片的商品外观与文案。
- 创作台显示的 Credits 是模型目录估算；实际扣费以服务端任务价格和 Credits 记录为准。当前报价接口尚未覆盖多张图片与视频。
- 不自动发布到淘宝、抖音、TikTok Shop、Amazon 等平台。下载并核对后由运营人员发布。
- 本次改动没有配置任何真实 Key，也没有发起付费模型调用或生产部署。
