# WEAVIA 桌面客户端与服务端产品需求 PRD

版本：v1.0 评审稿  
日期：2026-10-20  
状态：用于产品评审与开发拆分；本文不代表功能已经实现。  
范围：React / TypeScript / Tauri 客户端与 WEAVIA 服务端。

## 1. 已确认的产品决策

| 决策 | 已确认内容 |
| --- | --- |
| 用户 | 电商商家与运营、专业设计师、代运营和设计团队均覆盖 |
| 参考方式 | 借鉴首页交互、模型参数、素材和 Skill 组织方式，按电商任务重设计 |
| 核心路径 | 首页上传、选择模型与参数、直接提交；结果在同一创作会话出现 |
| 商品库 | 可选，上传即可开始；允许随后保存为商品 |
| 功能范围 | 主图、场景图、参考图改图、营销海报与套图、详情页、AI 模特与换衣、短视频、批量 SKU 全部需要 |
| 改造边界 | 同时规划客户端和服务端 |
| 视觉 | 金黄色操作色；采用用户截图中的居中标题、大输入框与底部工具栏布局 |

“全部需要”定义为首个完整版本的功能范围。工程按里程碑交付可测试版本；内部里程碑不等于完整版本上线。任何能力未完成真实输入、执行、结果与费用验证，均不得标记为正式可用。

## 2. 产品定位与用户

WEAVIA 是以商品资料与视觉素材为输入，制作、修改、管理和交付电商图片与短视频的桌面创作工具。

| 用户 | 核心任务 | 产品响应 |
| --- | --- | --- |
| 商家 / 运营 | 尽快获得可用商品内容 | 首页直接开始、场景预设、少量默认参数、批量导出 |
| 专业设计师 | 控制构图、品牌风格与版本 | 参数面板、明确的输入素材角色、局部调整、版本对比 |
| 代运营 / 团队 | 同时处理不同客户的多款商品 | 工作区、可选项目、品牌资料隔离、权限、批量任务与交付 |

三类用户使用同一套核心流程。高级能力逐步展开，首次创作不要求填写客户、项目、商品和 SKU 全部字段。

产品指标：首次可用结果耗时、有效提交成功率、结果下载/采用率、失败任务恢复率、每次被采用结果的 Credits 消耗、批量任务成功率。首轮内测先采集基线，再确定业务目标；不能用模拟任务成功率代替真实指标。

## 4. 信息架构

主导航建议：创作首页、创作场景、商品库、素材中心、作品中心、任务中心。账户与设置固定在底部，搜索保留在侧栏。

- 首页：首次输入和新建会话。
- 会话：首页提交后的工作界面；包含历史输入、任务进度、结果与继续修改。
- 创作场景：按业务结果分类；Skill 为其中的高级能力分区，创作工具栏可直接选用。
- 商品库：商品、SKU、事实、禁止添加的描述、关联素材和作品。
- 素材中心：上传资源与复用资源；支持从会话打开选择器。
- 作品中心：已生成结果、编辑版本、成套成果和交付。
- 任务中心：跨会话队列与异常处理，用户无需跳到这里等待单个结果。
- 图片编辑与视频分镜：从会话、作品和对应场景进入。
- 工作流编辑器：后续扩展；首版业务能力可由预设流程执行，不要求用户搭建节点。

首页与会话共享创作输入组件。现有 /create 的确认页职责并入会话；旧入口继续携带商品、描述和素材进入新流程。

## 5. 首页与会话交互

### 5.1 首页布局

```text
左侧导航        今天，为商品创作什么？
                 一句辅助说明
        ┌────────────────────────────────────┐
        │ 已选素材缩略图 / 上传进度            │
        │ 描述创作要求                         │
        │                                     │
        │ ＋  图片/视频 ▾  场景 ▾  模型 ▾  参数 │
        │ 商品（可选）       费用预估  [生成 ↑] │
        └────────────────────────────────────┘
           主图   场景图   营销套图   短视频
                  最近创作 / 最近商品
```

输入区居中，建议宽度 860–1040px；下方内容不抢占首屏主体。侧栏支持展开和收起。无全局顶部工作区横条；工作区切换可置于侧栏，页面内部允许自己的标题和工具栏。

### 5.2 工具栏

| 控件 | 操作及规则 |
| --- | --- |
| ＋ | 打开“上传文件 / 从素材库选择”；支持拖拽、粘贴。展示进度、失败重试、移除和用途标记 |
| 图片 / 视频 | 切换输出类型，重新筛选模型和参数；保留描述。已有不兼容素材要明确提示处理方式 |
| 场景 | 选择主图、换衣、套图等场景；补充专属字段。不得静默覆盖用户已经输入的描述 |
| 模型 | 显示名称、擅长任务、限制与可用状态；自动推荐必须返回实际选择结果 |
| 参数 | 比例、尺寸、数量、时长等由能力数据驱动；不支持的组合不可提交 |
| 商品 | 可选关联已有商品；没有商品也能生成。保存为商品允许生成后再完成 |
| 费用 | 显示当前报价、数量与单位；参数变化后重新报价，旧报价失效时明确提示 |
| 生成 | 校验、创建会话及任务，一次触发。上传未完成、报价失败或无可用模型时不可付费提交 |

模型和参数面板支持键盘、Esc 关闭、正确焦点返回。Enter 默认换行，Cmd/Ctrl+Enter 提交；中文输入法组合输入不触发提交。

### 5.3 提交后的同一会话

1. 首次提交创建会话并保留输入记录，页面转为会话内容区；用户无需再进入确认页。
2. 用户消息保存描述、素材、可选商品和参数快照。
3. 任务卡依次展示校验、排队、生成、保存结果；没有真实百分比时展示阶段，不编造进度。
4. 结果直接显示在任务卡下，可放大、下载、保存、对比、继续修改。
5. 用户选择一张结果再输入修改要求，创建关联到该版本的新任务。
6. 任务中心同步显示同一任务；点击可回到正确会话和结果。

“同一会话继续修改”意味着显式选定参考结果和当前输入，并不自动等同于模型原生多轮能力。服务端根据模型能力组织上下文，保留原版本。

### 5.4 异常与恢复

- 登录到期：保留草稿及素材，登录完成返回原会话。
- 网络中断：保留草稿；已提交任务先查询状态，不自动重复扣费。
- 重复点击/响应丢失：重用同一次提交的幂等键；真正的重新生成使用新键与新报价。
- 模型下线或参数过期：更新能力，保留其他输入；涉及费用或结果变化时由用户确认。
- 部分失败：保留成功结果，仅重试失败部分。
- 关闭客户端：服务端任务继续；重开后恢复真实状态。
- 取消：只在服务端确实可取消时提供；停止轮询不应被展示为已取消。
- 素材不可用：指出具体文件，允许重新选择，不清空整个表单。

## 6. 首个完整版本的功能要求

| ID | 能力 | 必需输入 | 输出与操作 | 验收要点 |
| --- | --- | --- | --- | --- |
| F01 | 商品主图 | 商品依据图、可选事实、目标规格 | 主图与版本、下载 | 目标规格准确，原商品信息可核对，不保证模型天然无失真 |
| F02 | 场景营销图 | 商品图、场景、用途 | 场景图片、多方案 | 保留商品依据，允许指定结果继续改图 |
| F03 | 参考图改图 | 目标图、修改要求；局部编辑需选区 | 新图片版本 | 原图不覆盖；不支持选区的模型不得显示局部编辑能力 |
| F04 | 活动海报与套图 | 商品、活动文案、品牌、输出渠道 | 单张海报或成套结果 | 文案可编辑/校对；每张图的规格、状态和结果对应清楚 |
| F05 | 详情页内容与图片 | 商品事实、卖点、模块选择、语言 | 有序模块文案与图片、组合预览 | 不凭空补充认证或功效；单模块重生成；可导出分图和约定格式 |
| F06 | AI 模特 / 换衣 | 服装图、模特图或允许的模特方案 | 模特展示图与版本 | 输入角色明确，图像一致性可人工比较；模型能力符合任务 |
| F07 | 商品短视频 | 商品图、描述、比例、时长；可选分镜 | 可播放视频、封面、下载 | 时长/规格真实传给服务；失败可恢复；有声能力另行标注 |
| F08 | 批量 SKU | 商品/SKU 清单、逐项素材、统一方案 | 批次和逐项结果、批量下载 | 提交前核对映射及总费用；部分成功不丢失；失败项可单独重试 |

图片数量不等于多张有不同意图的套图。套图需要独立的输出计划、逐图提示与状态；批量 SKU 需要每项商品对应关系。

视频首版最低交付为模型生成短片、封面及下载。配音、字幕和多镜头拼接作为视频能力的子项单独排期；这些能力未接通前不得通过按钮暗示已支持。

对于画面保真、字体错误、服装细节和商品变形，必须提供放大对比、重新生成及人工验收路径。质量门槛由一组真实商品样本测试确定，不能仅靠模型请求成功验收。

## 7. 商品、素材、作品与团队

### 7.1 商品可选

首次登录自动准备个人工作区与默认项目，后台保留归属；用户无需先手动建立项目。
纯文字生成不要求伪造输入素材 ID；图生图要求真实上传素材。商品/SKU ID 仅在用户主动关联时要求。

商品支持名称、SKU、品类、依据图、事实、限制、品牌归属和历史作品。编辑商品不会改变历史任务快照。上传后保存为商品应复用已有素材，不重复上传。

### 7.2 素材与作品

素材按商品图、参考图、品牌素材、背景、视频等分类，并记录用途、来源、归属、文件规格及引用关系。文件限制区分本地保存与云端生成，超过云端限制时允许压缩或重新选择。

删除被引用的素材应说明影响；历史任务必要输入快照或有效引用按保留策略处理。跨用户/工作区不得直接读取。

作品支持图片/视频预览、筛选、收藏、关联商品、版本、批次、导出。修改提示词并保存文字不算生成新图；“重新生成”“保存编辑”“修改说明”明确分开。

### 7.3 团队最低范围

建议角色：所有者、管理员、创作者、查看者。所有者管理成员与账单；管理员管理资源与创作；创作者只能在授权范围生成；查看者预览和下载授权结果。

客户/品牌通过工作区或项目隔离，资源、任务、账单均在服务端校验权限。成员邀请、项目分配和审核流属于团队交付阶段；没有权限闭环前不得宣称完整团队协作。

## 8. AI 分身、Skill 与工作流

以下为建议定义，用户尚未单独确认，当前不作为首轮实现的先决条件：

- 品牌助手（对应 AI 分身）：保存品牌语气、视觉偏好、禁用表达和适用品牌。仅在请求真正使用这些约束时启用。
- 模板：提供可编辑的提示词与默认设置。
- Skill：定义输入结构、执行步骤、支持模型、输出格式和版本；可调用模板或预设任务。
- 工作流：组合多个执行节点，需版本、依赖校验、失败恢复与费用控制。

界面提供快捷选择，已选项显示其具体影响。不得用“启用”状态代替真实执行接入。首版先满足业务场景；可视化任意工作流和第三方脚本执行列为后续扩展。

## 9. 视觉与组件规格

- 主按钮使用金黄色填充、深色文字；链接和选择态使用更深的金色；浅色与深色主题分别验证对比度。
- 保留目前金色方向，可沿用主按钮 #E7AE35、文字 #241800、强调文字 #A66A00；最终按实际主题验证。
- 中文系统字体用于主要操作和正文。正文建议 14–16px；少量辅助信息 12–13px；避免重要限制以小灰字呈现。
- 首页大输入框采用较大圆角，参数弹层和资源卡片较紧凑；减少重复大卡片。
- 图片缩略图是信息主体；比例选项配形状提示；操作图标有名称或可访问标签。
- 需要覆盖空、加载、失败、禁用、选中、上传中、执行中、部分成功、权限不足状态。
- 1000×700 最小桌面窗口仍可提交，工具栏允许换行，参数面板不遮住提交和错误说明；1440×900 验证主视图。
- 支持键盘焦点、屏幕阅读器名称、降低动画偏好；异步状态更新不抢夺输入焦点。

## 10. 现状差距与服务端改造

本节为代码检查结论，未声称完成运行环境联调：

| 现状 | 要求 |
| --- | --- |
| 首页把描述带到 /create 再提交 | 首页创建会话及任务，原地看结果；统一草稿 |
| 模型及大部分参数为客户端常量 | 后端统一输出可用模型、任务能力、字段约束和默认值 |
| 后端已有 catalog、estimate、presign、tasks 路由 | 核对返回结构并接入客户端；接口存在不等于整条流程已可用 |
| 后端校验固定为一张 1024×1024 图片 | 按任务类型与模型能力校验、转换并传给供应商 |
| 非 Mock 请求要求项目和输入素材 | 自动默认项目；纯文字模式不强制素材；商品关联可选 |
| 当前上传允许 PNG/JPG/WebP 且最大 5MB，客户端本地允许范围更宽 | 上传限制统一声明；预览、压缩与云端限制提示 |
| 当前供应商调用路径主要取首张参考图 | 明确多图角色与数量，完整传递，逐项验证所有权 |
| Live 客户端主要处理首张图片输出 | 支持多输出、视频、套图和批量结果 |
| 当前本地停止轮询可标为取消 | 建立服务端取消语义及结算，不误报取消成功 |

客户端负责布局、草稿、预览、输入联动和状态展示。服务端负责身份权限、能力目录、上传授权、参数校验、任务执行、供应商适配与计费。供应商密钥保留在服务端。

## 11. 接口与数据需求

现有路径以 /api 为前缀；“新增”表示建议契约，具体字段在接口评审中固定：

| 接口能力 | 现有 / 新增 | 契约要求 |
| --- | --- | --- |
| GET /api/ai/catalog | 已有，扩展 | 目录版本、模型 ID、类型、支持场景、可用状态、参数定义及组合约束 |
| POST /api/ai/estimate | 已有，扩展 | 全部有效参数、输出计划、报价 ID/有效期、总额度与明细 |
| POST /api/assets/presign；PUT upload URL | 已有，扩展 | 上传限制、类型、大小、素材归属；成功确认后才可用于任务 |
| 会话与消息接口 | 新增 | 创建/读取/分页、草稿、消息、任务与结果关联 |
| POST /api/ai/tasks | 已有，扩展 | 会话、幂等键、模型、参数、参考素材角色、商品快照、父结果、报价 |
| GET /api/ai/tasks/{id} | 已有，扩展 | 真实阶段、全部输出、错误码、可重试/可取消、费用状态 |
| 任务取消与重试 | 新增 | 供应商支持情况、取消中、最终状态、额度处理 |
| 批量任务接口 | 新增 | 父批次、逐项输入及状态、并发限制、单项重试 |
| 作品/版本/导出接口 | 新增或整合已有资产接口 | 版本关系、下载授权、导出包及失败恢复 |
| 团队及品牌能力 | 已有工作区基础上补齐 | 成员、角色、项目权限、品牌配置、资源归属 |

核心实体：User、Workspace、Project、Product/SKU、Asset、Conversation、Message、GenerationTask、Batch、Work/Version、ModelCapability、Quote、CreditTransaction。

关系：会话有多条消息；用户消息可触发任务；任务产生多个输出；作品版本指向具体输出或本地编辑结果；批次包含多个任务；商品对会话和任务均为可选关联。

模型参数定义至少包含：字段名、类型、选项/范围、默认值、条件依赖、服务端可用限制。切换模型要清理不兼容值并提示。UI 可缓存目录，但最终提交必须服务端复核。

费用规则：预估、预占、成功结算、失败释放各有账本事件；批量按成功/失败子项处理。上游已产生费用的取消规则必须明确显示，不能承诺所有取消都免费。结果保存故障需要恢复机制，避免重复请求上游。

## 12. 分阶段交付与验收

| 阶段 | 内容 | 阶段完成条件 |
| --- | --- | --- |
| M1 | 金色首页完整输入栏、会话、模型/参数、上传、主图/场景/参考改图 | 不建商品即可真实生成；结果原地显示；重启可恢复；参数实际生效 |
| M2 | 营销套图、详情页、品牌素材、版本与导出 | 按输出计划生成；逐项重试；文案可校对；成套导出 |
| M3 | AI 模特/换衣、商品短视频 | 使用对应可用模型；输入角色校验；视频播放下载与费用验证 |
| M4 | 批量 SKU、团队权限、交付 | 输入映射可核对；批次部分失败恢复；租户隔离与账单正确 |
| 完整版本 | 上述全部能力 | F01–F08 全部通过真实任务和用户验证，不能以模拟数据替代 |

进阶扩展：任意节点工作流、第三方 Skill 执行市场、完整多轨视频剪辑、平台自动发布及运营分析。不因参考站存在相关入口就自动纳入本次必做。

关键验收用例：

1. 不创建商品，上传商品图，在首页选模型/参数直接生成，在原会话看到可下载结果。
2. 纯文字任务正常运行，不要求伪造素材；不支持纯文字的模型明确提示输入要求。
3. 上传失败只重试文件，草稿保留；上传中的文件不能被提前提交。
4. 切换模型后不提交过期参数；目录更新和报价失效时保留用户内容。
5. 选定结果继续修改，产生新版本；原结果与参数快照可追溯。
6. 断网重连与重启恢复任务，重复点击和响应丢失不重复创建同一付费任务。
7. 任务成功、失败、取消与部分成功的账单一致；余额不足无隐式降级。
8. 批量 SKU 不串图，失败项重试不重做已成功项。
9. 查看者不能发起付费任务；其他工作区不能读到素材或结果。
10. 最小窗口与键盘操作下可完成上传、参数选择、生成、错误恢复和下载。

## 13. 待评审决策

下列细节不改变已确认的全部能力范围，建议在对应阶段开发前定稿：

- AI 分身/Skill 是否采用第 8 节定义。
- 首批模型供应商、可用额度与实际视频模型；界面从能力目录读取，不硬编码承诺。
- 各渠道首批图片规格、详情页导出格式；建议先 PNG/JPEG 分图和组合长图。
- 视频是否必须首版支持配音/字幕/多镜头成片，还是先验收生成短片。
- 团队是否共享钱包、成员是否设置预算、客户是否需要外部审阅链接。
- 历史素材与结果保留周期、云空间额度、删除与回收站规则。
- 批量导入先支持手动多项还是必须 CSV/Excel；建议逐项映射预览均为必需。
- 正式商用发布的会员权益、订单与支付范围；已有账户模块需要另外逐项联调，不在本文假定已经完成。
