# WEAVIA 运营后台与后端功能明细

日期：2026-10-29。后台是运营人员使用的 Web 管理页面；后端是 Go API、Worker、数据库、存储等系统服务。本文按代码盘点，不能据此认定部署配置或真实业务验收通过。

状态：**双端**＝后台页面与 API 均有代码；**服务端**＝有服务端实现，商家客户端未完全接入；**部分**＝只完成一部分或需复核；**待建**＝未发现完整闭环。后台页面上的操作仍须以服务端权限与业务约束为准。

## A01 后台入口、仪表盘与通用能力

代码：`server/apps/admin/app.js`、`index.html`；12 个顶层入口：仪表盘、用户中心、角色权限、商业中心、AI Studio、定价与成本、邀请码、存储、创作任务、内容管理、数据分析、设置。

| 编号 | 功能 | 细化操作/数据 | 状态与边界 |
| --- | --- | --- | --- |
| A01-01 | 管理员登录 | 邮箱/密码、会话 token、权限检查、退出 | 双端；不是普通用户自动获得管理员 |
| A01-02 | 后台 API 地址 | 默认本机/同源，设置页保存自定义地址 | 双端；不同于桌面构建固定地址 |
| A01-03 | 服务检测 | 检查服务状态、手动刷新 | 双端；不等于全部依赖与 Worker 健康 |
| A01-04 | 仪表盘 | 用户、订单收入、Credits、任务等汇总 | 双端；实际数值需生产数据校验 |
| A01-05 | 最近订单/任务 | 展示最近 6 项、跳对应管理页 | 双端；不是实时业务监控系统 |
| A01-06 | 表格辅助 | 列表检索/排序/客户端分页等通用增强 | 有页面逻辑；部分 API 最多返回最近 500 条，分页不代表全量查询 |
| A01-07 | 操作反馈 | 加载、错误提示、Toast、弹窗提交 | 有实现；需逐操作验收失败恢复 |

## 当前端后端尚未对齐的重点

1. 后端云商品/项目/SKU 与客户端本地商品不是同一完整管理链路。
2. 后端会员、积分流水、设备、会话、密码重置、注销申请已有服务，客户端仍部分占位。
3. 后端正式 quote 与前台估算/直接建任务并行，未统一收费入口。
4. 后台 OSS 存储切换、账户 OSS 权限、客户端同步开关是三个不同层次，应统一产品说明和执行链路。
5. Skill/AI 应用当前主要编译为单任务模板，不能按名称算作专用场景完成。
6. 会话服务、客户端单任务会话、DAG 运行记录是不同数据结构，当前未形成统一创作项目。
7. 存在新的 Provider/OSS 实现与旧部署说明不一致，需同步更新并逐项验收。
