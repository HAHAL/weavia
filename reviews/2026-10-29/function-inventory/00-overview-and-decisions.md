## 3. 数据归属：调整之前先明确“谁说了算”

| 对象 | 当前主要来源/落点 | 与另一端关系 | 调整时要决定的事项 |
| --- | --- | --- | --- |
| 用户/登录会话 | 服务端；客户端 token 缓存 | 认证已接入 | 邮件验证、密码恢复、设备与注销是否首版补齐 |
| 设备偏好/头像 | 客户端 | 没有完整云偏好同步 | 是否需跨设备；先不混入业务资产 |
| 商品/SKU | 客户端本地商品；服务端另有项目商品/SKU | 尚非同一套同步数据 | 选单机为主或云端为主，再设计迁移 |
| 商品事实/禁止声明 | 本机商品→任务快照 | 服务端保存任务输入 | 历史不可变；新商品编辑不应篡改旧任务 |
| 素材 | 本机文件或 data URL；上传参考图另存服务端 | 部分上传，不是全量同步 | 只同步被用到素材还是整库；备份与删除策略 |
| AI 任务 | 服务端权威；客户端缓存 | 已有列表、轮询、启动同步 | 任务/会话/项目的 ID 关联和恢复 |
| AI 原始输出 | 服务端生成物存储 | 客户端下载成素材 | 云端保留期、缓存、失效重下与计费 |
| 作品/版本 | 客户端 Work/WorkVersion | 服务端有任务/Asset，不是同等作品模型 | 建不建云端作品/版本，如何映射任务输出 |
| 核对状态 | 本机 Work | 尚无完整审核同步 | 按版本、审核人、时间、备注、权限 |
| Credits/报价 | 服务端账本/quote | 前台仍有本地估算 | 正式收费统一服务端权威价 |
| 模型/Skill/应用/示例 | 服务端发布、客户端缓存 | 已接目录同步 | 版本、灰度、下架对历史任务的影响 |
| DAG 定义/运行记录 | 服务端保存 | 客户端执行 | 客户端持久检查点与未提交节点恢复 |
| 分镜草稿 | 视频页面 state 为主 | 尚无完整云项目 | 刷新/退出保存、镜头与成片版本关系 |
| 助手凭据/引擎 | 原生隔离目录与系统凭据库 | 不等同普通模型服务端路由 | 客户是否自己配置、如何统一计费和随包分发 |

SQLite 仍为固定 `client_state.id=1` 快照，和 localStorage 的账号分区不同。账号隔离不能只依据浏览器分区测试判定已交付。

## 4. 当前已存在的业务流程

### 4.1 商品图片

```mermaid
flowchart LR
  A[本地建商品或直接描述] --> B[选参考图与模型参数]
  B --> C[客户端估算费用]
  C --> D[上传参考图并提交任务]
  D --> E[服务器校验与预占 Credits]
  E --> F[Worker 路由模型]
  F --> G[保存结果并结算]
  G --> H[客户端轮询与逐输出下载]
  H --> I[本机作品与核对]
  I --> J[下载文件人工发布]
```

缺口：正式 quote 未统一；跨设备商品/作品/审核未贯通；版本修改语义、失败重试快照和原生恢复需修正。

### 4.2 AI 编辑

作品或本地图片 → 图片编辑台 → 本地调整并保存，或输入 AI 修改要求 → 上传原图 → 新编辑任务 → 下载结果 → 追加版本或创建作品。

这与作品弹窗内“只修改提示词后保存新版本”是两种行为，后者没有生成新图。需要统一为用户可以理解的入口。

### 4.3 视频

商品/投放资料 → 手写或助手生成分镜 → 校验分镜 → 拼成一段视频描述 → 首页选择文字生视频模型 → 独立视频任务 → 下载播放。

缺口：商品依据图未作为当前视频输入；没有逐镜头任务和自动合成；分镜稿和最终视频不能混称完成品。

### 4.4 Skill / AI 应用

发布模板 → 生成输入表单 → 用户填写/选素材 → 提示词渲染 → 普通单个模型任务 → 结果。

与 DAG 的区别：模板主要规范一次任务；DAG 负责多个节点依赖。当前首页 Agent 模式主要调用模板，尚非自动规划多工具智能体。

### 4.5 运营配置

Provider/渠道/Key → 发现或手工接入模型 → 成本与售价 → 逻辑模型/路由/组 → 发布目录 → 客户端加载 → 任务和用量 → 账本/审计。

缺口：配置成功、目录可见、真实调用成功、结果质量合格是不同验收层级。

## 7. 核心规则及当前已知冲突

| 规则 | 当前实现/冲突 | 调整约束 |
| --- | --- | --- |
| 商品事实 | 用户确认后注入模型；没有自动验证真伪 | AI 提取的候选事实不能直接标“已核实” |
| 图片上传限制 | 浏览器本地 2MB、原生本地 10MB、云端参考上传 5MB、编辑页提示 15MB | 统一按实际上下文展示，不能到最后才报错 |
| 费用 | 首页估算、服务端单图 quote、任务结算 | 报价与参数快照绑定，变化后重新确认 |
| 生成重试 | 结果补取已有；重新生成只恢复提示词 | 区分不收费的结果恢复与新的付费生成 |
| 版本 | 描述保存和 AI 新资产都可叫版本 | 分清备注版本、编辑资产版本、生成版本 |
| 审核 | 作品级状态；编辑追加版本可能继承状态 | 必须明确新版本是否需要重新核对 |
| 同步 | 目录/任务同步存在，商品/作品审核不同步 | 不使用笼统“全部云端同步”承诺 |
| DAG | 客户端执行，关闭中断，云端存定义与记录 | 检查点和恢复留在客户端 |
| 视频 | 脚本合并为单次文字视频输入 | 不承诺商品图驱动或多镜头成片 |
| 模型适配 | 有适配文件不等于 API/Worker 都已注入 | 检查目录、路由、Key、运行进程、请求/结果全过程 |
