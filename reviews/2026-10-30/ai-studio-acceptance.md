| 页签 | 9 个收成 5 个：**健康看板 / 模型 / 渠道与 Key / 调用日志 / 分组与价格**；Skill 审核和 AI 应用移到「内容管理」 |

## 1. 模型用途怎么定

| 用途 | 客户端出现在哪 |
|---|---|
| 文生图 | 首页图片模式，没选商品/参考图时 |
| 参考图生图 | 首页图片模式，选了商品或参考图时；套图、爆款复刻首帧 |
| 图片编辑 | 作品「重新生成新版本」、图片编辑页 |
| 文生视频 | 视频模式，没选首帧图时 |
| 图生视频 | 视频模式选了首帧图时；爆款复刻 |
| 参考生视频 / 视频编辑 | 暂不在客户端开放，先标对，后续接入 |
| 视觉理解 | 不进客户端模型列表，填到「客户端发布 → 视频复刻模型」 |

**重要：** 目前线上很多图片模型（GPT-Image、Nano Banana、Gemini、Qwen-Image-3.0 等）只标了「文生图」，所以选了商品后它们会显示「不支持商品参考图」。请按供应商文档逐个确认是否支持参考图，支持的在「模型 → 编辑」里勾上「参考图生图」。推荐按钮只是按名字猜，不会自动改。

## 3. 后台验收（部署后，约 15 分钟）

1. AI Studio → **健康看板**：应看到「Computrix MaaS」相关告警（之前 Key 被拒），以及所有「客户端可见但不可用」的模型。
2. **渠道与 Key** → Computrix MaaS →「测试」：期望逐把 Key 显示结果；无效 Key 显示「Key 无效或无权限」。更新有效 Key 后再测应显示「连接正常，供应商返回 N 个模型」。
3. Key 列表里点「停用 / 启用 / 测试」：期望按钮生效（以前弹窗按钮无反应）。
4. **模型** → 筛选「有问题」：逐个处理（修渠道或隐藏）。编辑一个模型：点「按模型名推荐」→ 勾选用途 → 填说明和标签 → 保存。
5. 模型 →「路由」：看到渠道列表和最近调用；调整优先级后保存。
6. 渠道 →「发现模型」：期望每行有推荐用途；把一个已有模型的同名模型勾选并在「接入为」填它的 Key → 接入后该模型「渠道」数 +1，名字/价格不变。
7. **调用日志**：选「24 小时 / 失败」，点错误码汇总里的 AUTH_FAILED → 列表只剩这类；点「任务」打开时间线。
8. 内容管理：看到「示例与模板 / Skill 审核 / AI 应用」三个页签。

## 4. 客户端验收（安装 0.3.1）

1. 首页不选商品打开模型列表：分组「文生图」，底部显示「N 个图片模型 · 可用 M 个」。
2. 选一个有依据图的商品：只支持文生图的模型仍在列表里，置灰并标「不支持商品参考图」。
3. 在后台把某模型勾上「参考图生图」→ 客户端重新打开模型列表（无需重启）→ 该模型变为可选。
4. 后台隐藏一个模型 → 客户端重新打开列表 → 该模型消失。
5. 在后台给模型填写说明和标签 → 客户端模型列表显示说明和标签。
