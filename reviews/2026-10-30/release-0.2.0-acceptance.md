# WEAVIA 0.2.0 验收步骤（2026-10-30 晚发布）

本次发布内容、已部署位置和你需要逐项点验的步骤。每一步写了「期望结果」，不符合就记下截图和时间发给我。

## 0. 本次改了什么

| 范围 | 改动 |
|---|---|
| 后端 | 报价支持所有比例、1–4 张、视频；报价和扣费用同一条计价规则（≤1280px 1×，≤2048px 2×，更大 4×）；报价按账户分组价计算 |
| 后端 | 渠道明确拒绝（Key 无效 401/403、限流 429、不可用 503、网络不通）时自动换下一个渠道，最多 3 个；可能已被受理的失败不换，避免重复计费 |
| 后端 | 新接口：`GET /api/client/config`、`GET /api/announcements`、`POST /api/showcase/{id}/use`；后台接口 `/api/admin/client-config`、`/api/admin/announcements` |
| 后端 | CORS 放行 `If-None-Match`、`Idempotency-Key`（启动同步不再永远走缓存） |
| 数据库 | 迁移 `0026_client_ops.sql`：`client_config`、`announcements`、灵感示例新增 媒体/模型/比例/清晰度/张数/使用次数 |
| 后台 | 新页面「客户端发布」：API 地址、最低版本、最新版本、下载地址、更新说明、公告管理；内容管理增加「一键同款」参数和使用次数；地址栏可定位页面（如 `#/client`），刷新不丢页 |
| 客户端 | 版本 0.2.0；强制升级拦截页；公告（侧栏铃铛 + 重要公告顶部横幅）；API 地址可由后台下发并自动切换 |
| 客户端 | 灵感广场「做同款」：一键带入提示词、模型、比例、清晰度、张数 |
| 客户端 | 提交任务时网络断开会用同一幂等键重发，不会重复扣费；任务「重新生成」带回商品、参考图、模型、比例、张数、渠道 |
| 客户端 | 进度改为阶段文字（排队中 / 提交中 / 模型生成中 / 结果保存中），不再显示假百分比 |
| 客户端 | 导航：隐藏视频工作台、工作流；「能力」改名「模板」；英文标题改中文；作品页去掉重复的「生成记录」；账户页「应用设置」改为「高级设置」，「订单记录」改为「充值说明」（线下充值） |
| 客户端 | 删除未使用的 `Dashboard.tsx`、`Features.tsx` |

## 2. 后台验收（约 10 分钟）

1. 浏览器打开 `http://8.160.190.182:3001`，用管理员账号登录。
   - 期望：左侧导航多了「客户端发布」（第 12 项），编号显示 `12` 而不是 `012`。
2. 点「客户端发布」。地址栏应变为 `…:3001/#/client`；按 F5 刷新。
   - 期望：刷新后仍停在「客户端发布」。
3. 「连接与版本」先只填：最新版本 `0.2.0`、更新说明随便写一句，**最低版本先留空**，点保存。
   - 期望：提示「已保存」，「最后保存」时间更新。
4. 「公告」→ 新建公告：标题「测试公告」，正文两行，级别「重要」，状态「发布」，置顶「是」，时间留空 → 创建。
   - 期望：表格出现这一行，状态「已发布」。
5. 「内容管理」→ 编辑任意一条示例：模型 Key 填 `qwen-image-2.0`，比例 `3:4`，清晰度 `1K`，张数 `2` → 保存。
   - 期望：卡片下方出现「一键同款：图片 · qwen-image-2.0 · 3:4 · 1K · 2 张」。

## 3. 客户端验收（约 20 分钟）

先安装：双击 `WEAVIA Desktop.app`（在 Finder 里打开 `client/src-tauri/target/release/bundle/macos/`）。首次打开若被系统拦截：右键 → 打开。

1. **启动与登录**：登录你的账号。
   - 期望：正常进入首页；账户 → 高级设置 → 偏好设置 里显示「客户端版本：0.2.0」和当前 API 地址。
2. **公告**：
   - 期望：页面顶部出现「测试公告」横幅；侧栏「公告」铃铛显示红色数字 1。点横幅或铃铛 → 弹出公告列表；关闭后红点消失，横幅不再出现。
   - 回后台把公告下线，客户端 5 分钟内（或重启后）不再显示。
3. **导航**：
   - 期望：侧栏没有「视频工作台」「工作流」；分组标题为「模板」，下面是「Skill 模板」「AI 应用」；「图片编辑」页标题为中文。
4. **做同款**：首页往下到「灵感广场」，点刚才设置了参数的那张。
   - 期望：提示「已带入…的提示词和参数」；参数里比例 3:4、张数 2、模型为 qwen-image-2.0；后台该示例「已被使用」次数 +1（刷新内容管理页）。
5. **非方图报价（修复验证）**：保持 3:4、1 张，选一个商品或直接写提示词。
   - 期望：右下角出现服务端报价（不是「计算中」也不是报错）。改成 2K，报价应翻倍。
6. **套图报价**：打开套图计划，把某一行比例改成 3:4 或 16:9。
   - 期望：该行显示具体 Credits，不再是「—」。
7. **真实出图（会扣 Credits，约 10–30）**：提交 1 张 1:1。
   - 期望：任务详情「阶段」依次显示 排队中 → 模型生成中 → 已完成；结果出现在作品；Credits 扣减 = 提交前看到的报价。
8. **重新生成**：在任务中心打开一个任务 → 重新生成。
   - 期望：回到首页时，提示词、商品、比例、张数、模型都已带回。
9. **作品页**：
   - 期望：右上角是「任务中心」按钮，不再有「生成记录」页签。
10. **充值说明**：账户 → 充值说明。
    - 期望：显示线下充值说明和你的账户邮箱。

## 4. 强制升级验收（最后做）

1. 后台「客户端发布」：最低版本填 `0.3.0`，最新版本 `0.3.0`，macOS 下载地址随便填一个 https 链接 → 保存（会弹确认框）。
2. 客户端点「重新检查」不可用（还没被拦），所以直接**退出并重新打开**客户端。
   - 期望：整屏出现「需要升级到新版本」，显示当前 0.2.0、更新说明、「下载新版本」按钮；点按钮会用浏览器打开下载链接；无法进入任何页面。
3. 后台把最低版本改回 `0.2.0`（或清空）→ 保存；客户端点「重新检查」。
   - 期望：拦截页消失，回到正常页面。

> 注意：0.1.0 老客户端没有拦截能力，最低版本对它们无效。需要所有人升级时，先把 0.2.0 包发给客户，再在后台调高最低版本。

## 5. 换域名（以后用到时）

1. 把域名解析到服务器，配好 HTTPS 反向代理到 8080，确认 `https://新域名/api/health` 能打开。
2. 后台「客户端发布」→ API 地址填 `https://新域名` → 保存。
3. 客户端（0.2.0 及以后）下次启动或 5 分钟内会先探测新地址，能连通才切换；连不通继续用旧地址。
4. 后台本身用新域名访问时，登录页「API 地址」也要改成新域名。
5. 旧 IP 地址至少保留一个月，给还没启动过的客户端完成切换。
