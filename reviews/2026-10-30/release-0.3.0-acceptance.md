## 2. 后台（10 分钟）

1. 「用户中心」→ 任意用户「调整 Credits」→ 类型选「线下充值入账」，金额 1，凭证号 `TEST-001`，确认。
   - 期望：成功。再对**另一个用户**用同一凭证号入账 → 提示「该凭证号已入账到其他账户」。
2. 同一用户「重置密码」→ 输入 8 位以上临时密码。
   - 期望：提示已保存；该用户客户端被退出，用临时密码可登录。
3. 「创作任务」→ 打开一个**本次部署后**产生的成功任务 →「执行时间线」有 进入队列 / 开始生成 / 渠道生成 / 已结算 几行；点「设为模板（草稿）」→ 到「内容管理」看到草稿，带封面和参数，发布它。
4. 「客户端发布」→ 最新版本改为 `0.3.0`，更新说明写一句，保存。

## 3. 客户端（30 分钟，先安装 0.3.0）

1. **模板库**：侧栏「模板 → 模板库」。期望：官方模板按使用次数排序；搜索和标签筛选可用；点「做同款」回到首页并带入参数。
2. **商品变量**：在后台把某个模板提示词改成「把{商品名}放在大理石台面上，突出{卖点}」→ 客户端做同款 → 选一个商品。期望：提示词里的变量被替换成商品名和已核实事实前 3 条。
3. **我的模板**：作品中心打开一件作品 →「存为我的模板」→ 模板库「我的模板」出现，可做同款、可删除。
4. **套图成批 + 工作区**：首页「商品套图」提交 3 张。期望：自动进入创作页，顶部「本套」显示 3 个缩略位，逐张出图；可在这里直接「核对通过 / 需修改」。
5. **交付台批次**：交付台顶部出现这一批，显示「通过 x/3」；点它只看这一批。
6. **客户审阅**：选中这一批 →「发给客户审阅」→ 链接自动复制。用手机打开：能看图、写称呼、点通过或写意见点需修改。期望：1 分钟内客户端交付台对应作品出现「客户已通过 / 客户要修改」和意见；底部「客户审阅链接」显示计数；撤销后链接打开显示「已失效」。
7. **版本级核对**：把一张图核对通过 → 作品中心对它「重新生成新版本」→ 新版本回到「待核对」。
8. **取消任务**：连续提交几张让任务排队，在任务中心对「排队中」的任务点取消。期望：状态变已取消，余额退回（生成中的任务不可取消，会提示）。
9. **商品同步**：在 A 电脑新建商品 → 在另一台电脑（或删除本机数据后）登录同一账号。期望：商品资料出现（依据图需要重新上传）。
10. **账号隔离**：A 账号登录建一个商品 → 退出 → B 账号登录 → 重启客户端。期望：B 看不到 A 的商品和作品。

## 4. 视频（花 Credits 较多，单独做）

1. **配置视觉模型**：后台「客户端发布」→ 拆解渠道选 `volcengine`，视觉模型 ID 填火山方舟里**已开通**的多模态模型 ID（在火山方舟控制台「模型推理」里复制）→ 保存。
2. **图生视频**：首页切到视频，选一个有依据图的商品，选 Seedance 模型，写一句运镜描述生成。期望：报价正常，出 5 秒视频，首帧是商品图。
3. **爆款复刻**：侧栏「创作工具 → 爆款复刻 · 测试版」→ 上传一条 15–30 秒竖版参考视频 → 勾选授权 → 拆解分镜。期望：30–60 秒内出现 3–8 个镜头，可改时长、画面、字幕。
4. 选商品、首帧模型、图生视频模型 →「生成全部镜头」（会提示将提交多少个任务）。期望：每个镜头依次「生成首帧中 → 生成视频中 → 已完成」；失败的镜头可单独重做。
5. 「合成 9:16 成片」（可选背景音乐）。期望：按实际时长实时录制完成后可预览、下载，并保存到素材中心。

## 5. 已知限制

- 视频拆解每人每天 30 次，暂不收费；首帧和视频按各自模型正常扣费。
- 本机合成用系统自带录制能力：画面 + 字幕 + 背景音乐，不含 AI 配音；输出格式取决于系统（macOS 一般为 MP4，否则为 WebM）。
- 商品云同步只同步资料，不同步依据图文件。
- 审阅链接只包含云端结果；纯本机编辑的版本不会进入链接（交付台会提示跳过几张）。
- 视频与爆款复刻标为「测试版」，第 4 节验收通过前不建议对客户宣传。
